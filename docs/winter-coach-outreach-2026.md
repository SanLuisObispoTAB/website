# Winter 2026-27 coach outreach

Drafted 2026-11-23 (decision #269) from `npm run team-audit` and the school's
Winter Sports page (`slohs.slcusd.org/athletics/winter-sports`, coach names and
emails verified the same day). One email per head coach; Coach McDonald gets one
covering Winter Cheer and Traditional Competitive Cheer. These were saved as unsent
Gmail drafts in Erik's account; this file is the record of what was asked.

When replies come in: apply them to `src/app/data/teams/<slug>.json`, then
`npm run team-audit -- --write`. Rosters are name + grade only (#235).

Reply with whatever is handy; partial is fine, and I'll post pieces as they arrive. Photos can come as attachments or a shared album link.
